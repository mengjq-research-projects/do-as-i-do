# Do as I Do 到 Isaac 的适配性评估

日期：2026-08-09

项目：从单目 RGB 人手-物体交互视频重建 3D 场景与交互动作，并在 Isaac 中可视化回放

## TL;DR

**Do as I Do 可以作为将“夹爪 RGB 视频输入”替换为“人手-物体 RGB 视频输入”的 reconstruction baseline。它直接适用于刚体物体场景。**

它能够恢复手与物体的几何和时序运动信息，可用于在 Isaac 中复现手物交互动作。当前主要新增工作是完成重建结果到 Isaac 的坐标、尺度和时序适配。

首轮成功标准：

```text
单目 RGB 人手-物体视频
  -> 手与物体的几何和运动重建
  -> Isaac 中复现手与物体的交互动作
```

## 2. Limitation

当前需求包含柔性物体的交互重建，但 Do as I Do 的物体重建主要适用于刚体物体。因此，它可以作为刚体场景下的人手 RGB reconstruction baseline；对于柔性物体，仍需要额外的重建与建模方案。

## 3. Isaac 接入需要做什么

Isaac 接入的目标是将重建结果恢复为可视化场景，并按视频时间顺序复现手与物体的交互动作。需要完成的工作包括：

1. 将重建出的手和物体几何导入 Isaac；
2. 将手和物体的时序运动结果导入 Isaac 并进行回放；
3. 统一视频重建结果与 Isaac 场景之间的坐标和尺度。

## 4. 待提供信息

1. **原始 RGB 视频**：一只手与一个明确的刚体物体交互，手和物体在大多数帧中清晰可见，尽量不裁剪、不拼接；
2. **基本标注**：物体名称、主交互手（左 / 右）、一个手和物体都清晰的参考帧；
3. **尺寸信息**：物体至少一个真实长度，用于确定 Isaac 中的尺度；
4. **视频信息**：分辨率和帧率；
5. **采集条件**：固定相机、单一物体、光照清晰，避免严重遮挡、反光和快速运动。

## 5. 首轮验证计划

1. 使用项目自带示例视频和已有结果，验证从 reconstruction 到 Isaac 的转换流程。
2. 收到一段待验证视频后，运行 reconstruction 并在 Isaac 中复现手与物体的交互动作。
3. 检查手物运动是否连续、动作是否与原视频一致、尺度是否合理。

## 6. 待确认事项

1. 第一轮是否限定为固定相机、单一刚体物体和单手操作？
2. 是否将“在 Isaac 中复现手与物体的交互动作”定义为第一阶段验收标准？
3. 是否需要提供物体尺寸信息？
4. 是否具备运行完整 reconstruction 所需的计算资源和模型访问权限？
