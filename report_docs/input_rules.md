# Do as I Do 输入视频规则

## 适用范围

本项目用于处理单目 RGB 人手-物体交互视频，当前优先支持**刚体物体**。

## 建议使用的视频

- 一只手与一个明确的刚体物体持续交互；
- 手、物体和主要运动过程在大多数帧中清晰可见；
- 视频为连续片段，没有剪辑、跳帧或镜头切换；
- 相机固定或运动很小；
- 画面光照稳定，物体与背景容易区分；
- 物体为不透明、低反光、形状稳定的常见物体；
- 原始视频优先保存为 MP4。

## 暂不建议作为首轮输入

- 柔性或明显变形的物体，例如布料、绳子、软袋、面团；
- 手或物体频繁出画、长期完全遮挡；
- 强烈相机运动、快速变焦、严重运动模糊；
- 多个物体频繁切换，或多个手同时进行复杂交互；
- 剪辑拼接的视频；
- 透明、镜面反光、极薄或纹理过少的物体。

## 随视频附带的信息

1. 目标物体名称；
2. 主交互手：左手或右手；
3. 一个手和物体都清晰可见的参考帧；
4. 视频分辨率和帧率；
5. 物体至少一个真实尺寸，用于尺度对齐。

## 首轮建议

先使用固定相机拍摄的单手、单个刚体物体、一镜到底的视频验证流程；成功后再逐步测试网络视频、第一视角视频或更复杂场景。
